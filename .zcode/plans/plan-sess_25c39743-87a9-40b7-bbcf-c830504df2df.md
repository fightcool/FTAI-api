# 渠道级「用量/余额查询模板」功能 + DeepSeek 余额修复

## 目标

在渠道配置中新增一个自定义 JSON 模板字段,按你实测的 uuapi 模板格式(`kind/url/method/mapping/unit`),对任意渠道类型精准查询上游用量与余额;同时修复 DeepSeek 余额币种错位 bug(6.79 CNY 被当 USD 存储再 ×7.3 显示成 49.57)。

模板格式完全兼容你们已有资产,例如:
```json
{
  "kind": "template",
  "url": "{baseUrl}/usage",
  "method": "GET",
  "mapping": {
    "balance": "balance", "remaining": "remaining",
    "used": "usage.total.actual_cost", "currency": "unit",
    "scope": "planName", "available": "isValid"
  },
  "unit": "USD"
}
```

## 后端

### 1. relaykit/dto/channel_settings.go — 新增模板 DTO 与校验

- 新增 `ChannelUsageQueryTemplate`(字段 `kind/url/method/mapping/unit`)+ `UsageQueryMapping`(`balance/remaining/used/currency/scope/available`,值为 gjson 点路径)。
- `Validate()`:url 必填(含 `{baseUrl}` 占位或 `http(s)://` 开头);method ∈ {空,GET,POST};balance/remaining 至少映射一个;unit ∈ {空,USD,CNY};kind 为空或 "template"。
- `ChannelOtherSettings` 增加 `UsageQueryTemplate *ChannelUsageQueryTemplate `json:"usage_query_template,omitempty"``;`model/channel.go` 的 `ValidateSettings()`(channel.go:971)调用其 Validate。
- relaykit 保持独立:只用 gjson 做校验不需要,DTO 纯结构体,无 root 依赖。

### 2. controller/channel-billing.go — 模板执行与 DeepSeek 修复

- 新增 `fetchUsageTemplateBalance(channel)`:
  - URL:`{baseUrl}` 替换为渠道生效 Base URL(`GetBaseURL()`,含类型默认值);
  - 请求头:默认 `Authorization: Bearer <渠道密钥>`,再复用现有 `applyFetchModelsHeaderOverrides`(channel.go:223)应用「请求头覆盖」(支持 `{api_key}`,即自定义鉴权无需新配置);
  - 安全框架复用 `fetchAdvancedCustomBalance` 的:响应 256KB 上限、JSON 校验、代理、`sanitizeFetchModelsError/ sanitizeAdvancedCustomRequestError` 脱敏;
  - 解析:拆出**纯函数** `parseUsageTemplateResponse(body, tpl)`(不碰 DB,便于测试),gjson 取各 mapping 路径,数字兼容字符串形式,NaN/Inf 拒绝;
  - 币种:mapping.currency 优先,否则模板 unit,默认 USD;CNY 值除以 `operation_setting.USDExchangeRate`(option.go:469 管理后台可配)转 USD;
  - 存储:`remaining` 优先、`balance` 兜底 → `channel.UpdateBalance(USD值)`;两者都缺失 → 返回 raw_response,不落库。
- `updateChannelBalance` 优先级:**模板 > AdvancedCustom 余额路由 > 内置类型逻辑**。
- `UpdateChannelBalance` 响应增加 `usage` 对象 `{remaining, used, currency, scope, available}`(原始币种值),`balance` 仍为存储的 USD 值(前端现有更新链路不变)。
- **DeepSeek 修复** `updateChannelDeepSeekBalance`:URL 改用 `channel.GetBaseURL()`(默认仍是官方地址,可测),CNY 余额除以 `USDExchangeRate` 后再存(对齐 Moonshot 做法、但用正规汇率变量)。
- 自动维护零成本接入:定时任务(`CHANNEL_UPDATE_FREQUENCY`)与「余额 ≤0 自动禁用」走现有 `updateAllChannelsBalance`,模板渠道自然生效;多密钥渠道维持不支持。

## 明确不做

- 渠道卡片「已使用」列不改语义(保持本站统计,上游 used 只在查询弹窗展示);
- `available=false` 不触发自动禁用(仅展示),自动禁用仍只看余额 ≤0;
- 不新增请求体模板(查询接口 GET/POST 空-bodied 已覆盖你的实测场景)。
